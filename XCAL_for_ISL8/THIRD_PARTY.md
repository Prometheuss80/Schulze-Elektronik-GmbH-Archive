# Third-party components and redistribution

The source archive includes various materials of uncertain or independent authorship. They have been **excluded from this GitHub package**, pending verification of their rights:

- `RPI_PICO-20260406-v1.28.0.uf2`, `RPI_PICO2-20260406-v1.28.0.uf2` — MicroPython firmware builds. Get the appropriate firmware from [micropython.org](https://micropython.org/download/).
- `flash_nuke.uf2` — RP2040 flash reset tool; obtain from its original project.
- `Pico-Pinout-Pico-R3-SDK11-Pinout.svg.webp` — Pico pinout illustration.
- `tl431.xls` — legacy third-party engineering spreadsheet; file metadata names Philip D. Rogers (2000) as author.
- `ssd1306.py` — MicroPython SSD1306 display driver; obtain from the official MicroPython project, observing its license.
- `schulze.jpg`, `schulze.pbm` — Schulze-logo imagery; original brand/trademark rights have not been established for redistribution.

The package contains only the original XCAL project source (`main.py`, `ads1115.py`, two tests), project-made splash art and original documentation. Original Schulze firmware is not included.
